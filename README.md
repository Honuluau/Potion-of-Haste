# Potion of Haste
## Basics
A 26.2 Fabric Mod that adds 4 variants of a potion of haste to Minecraft. There are levels 1 and 2 for haste which can be 3 or 8 minutes.

| Potion | Duration | Recipe                           |
|---|---|----------------------------------|
| Potion of Haste | 3 min | Swiftness Potion + Golden Apple  |
| Potion of Haste II | 3 min | Haste Potion + Glowstone Dust    |
| Long Potion of Haste | 8 min | Haste Potion + Redstone Dust     |
| Long Potion of Haste II | 8 min | Haste II Potion + Redstone Block |

> [!TIP]
> Potions of Haste are brewed by adding a golden apple to a swiftness potion. 

> [!IMPORTANT]
> Java 21
> Fabric Loader >=0.19.3

## Installation
Check releases for .jar files or build by cloning this repo and using gradlew.
